## [2.0.0] - 2026-11-21

基于 Cover Studio 二次开发的第一个版本，面向企业 HR 和培训部门。

### 新增

- **培训海报品类**：在弹窗里填写主题、受众、时间地点、文案、课程内容和讲师（最多 6 位），保存后自动拼出完整提示词；视觉风格、配色和版式交给 AI 判断。（97ccf40、1c93be7）
- **讲师肖像参考图**：千问生图时，把讲师照片作为参考图一起发送；有三种呈现方式：主讲人出镜、肖像 + 简介、仅文字。照片在浏览器里压缩成长边 1600 px 的 JPEG；超出模型上限（3 张，`qwen-image-2.1` 系列为 10 张）的讲师按虚构形象绘制，并提前提示。（c5df552、15a6e11）
- **千问生图接入**：支持百炼原生 DashScope 接口和兼容模式，自动判断该走哪一种；生图可以在千问和 MaaS 之间切换，拆层仍然用 MaaS。（bacb5aa、c5df552、15a6e11）
- **设置弹窗**：封面图和培训海报的设置都改成「按钮 → 弹窗 → 保存后更新提示词」。保存时如果提示词手改过，会先确认再覆盖；切换生图接口、模型或比例后，没手改过的提示词自动重新拼，手改过的显示「重新拼装」提示条。（1c93be7、15a6e11）
- **封面风格看图选择**：31 种 Punk 风格改成图片网格，示例图来自 Punk-Skill `v1.0.0-mit`。（a0df7ab）
- **「载入示例」换成培训海报**：8 个图层，包括讲师人像、标题、信息栏等。（035d196）
- **清空画布按钮**：画布回到初始状态，提示词、表单和素材库都保留；有未导出的图层调整时会先确认。（5bf9ee0）
- **AI 识别填入**：在培训弹窗里粘贴通知原文，或上传 txt、md、docx 文件，由千问文本模型（默认 `qwen-plus`）提取信息，替换整张表单；同名讲师保留已上传的肖像，识别出的内容标黄，点「取消」可以撤回。（b9bf762）
- **Windows 启动脚本 `启动.bat`**：自动查找 `py -3`、`python` 或 `python3`。（e0bb9c6）
- **开发文档**：README、文档索引、接手指南、技术架构、接口文档、开发规范、变更日志、问题待办。（96958db、65e9b17 及之后）

### 变更

- 品类调整为封面图、培训海报、自由创作三个，删除小红书品类和电商示例。（2e2f114）
- API 设置分成「生图接口」「千问 · 阿里云百炼」「拆层接口 · MaaS」三组。千问那一组始终显示，因为 AI 识别也要用千问 Key。（15a6e11、b9bf762）
- 整体配色由绿色系改为暖灰底配近黑色主色，与培训海报生成器保持一致；画布上选中图层的框改为蓝色。（5bf9ee0）
- 网站名称、空白页文案和 README 开头改成不局限于培训海报的说法。（81075fd、a91cd31）
- 生成前，如果提示词和当前的生图设置或表单对不上，会先弹窗确认。（a9e0789）

### 修复

- 中文 Windows 上素材库读不出来：原因是 manifest 写入时没指定 UTF-8。（e0bb9c6）
- 素材库「载入画布」点击无反应：代码还在调用一个已删除的函数。（655a5aa）
- 载入历史提示词后，提示词和实际发送的肖像可能对不上：现在会显示提示条。（655a5aa）
- 结果图片下载失败时，报错误写成「Key 无效」：现在会提示「结果图片下载失败」。（a9e0789）
- 「仅文字」模式下，只上传了照片的讲师会显示成「特邀讲师」。（a9e0789）

### 删除

- Cloudflare Workers 部署（`cloudflare/`、`wrangler.jsonc`、`static/cloud.js`）。（2e2f114）
- 小红书模板（`ponyo-cover.js` 及其第三方规则）。（2e2f114）
- 电商示例提示词 `example-prompt.txt`。（2e2f114）

## 基线：Cover Studio

V2 从 `../cover-studio` 复制而来（提交 e0bb9c6）。复制时继承的功能：AI 生图、拆层、图层编辑（拖动、缩放、显隐、锁定、排序、撤销）、多种比例导出、素材库、Punk 封面风格。
