# 接口文档

本机服务的默认地址是 `http://127.0.0.1:8765`。所有接口：

- 只接受本机访问：Host 必须是 `127.0.0.1:<端口>` 或 `localhost:<端口>`；如果请求带了 Origin，也必须是这两个地址。
- 都返回 JSON。出错时返回 `{"error": "中文说明"}`，状态码为 400、403、404、413 或 429。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | `{"ok": true}` |
| GET | `/api/config` | 本机配置（`.env`）和默认 Key |
| GET | `/api/assets` | 素材库列表 |
| POST | `/api/jobs` | 提交生成或拆层任务（异步） |
| GET | `/api/jobs/<id>` | 查询任务状态 |
| POST | `/api/extract` | AI 识别填入（同步） |
| POST | `/api/assets/delete` | 删除素材（移进 `output/.trash/`） |
| POST | `/api/assets/restore` | 恢复素材 |
| GET | `/output/<id>/<文件>` | 读取产物文件 |
| GET | 其他路径 | `static/` 下的静态文件 |

### GET /api/config

```json
{"runtime": "local", "source": ".env",
 "default_key": "<MAAS_API_KEY>", "default_qwen_key": "<QWEN_API_KEY>",
 "gen_provider": "qwen", "qwen_image_model": "qwen-image-3.0-pro", "qwen_text_model": "qwen-plus",
 "qwen_base_url": "https://dashscope.aliyuncs.com/api/v1"}
```

- 每次请求都重新读取 `.env`，所以改完 `.env` 刷新页面即可生效。
- Key 为空时回退到旧的 `.local-key` / `.local-qwen-key` 文件；`source` 为 `.env`、`.local-key` 或空字符串，表示 Key 从哪里来。
- 不合法的值返回空字符串（`gen_provider` 只能是 `qwen`/`maas`，模型名只能含字母数字 `_.-`，地址必须是 https，Key 最长 512 字符），前端遇到空值就保留页面默认值。
- `PORT` 不在返回值里，只在启动时由 `server.env_port()` 读取，作为 `--port` 的默认值。

### POST /api/jobs

**生成 · MaaS**

```json
{"kind": "generate", "provider": "maas", "key": "<MaaS key>", "prompt": "…", "ratio": "3:4"}
```

**生成 · 千问**

```json
{"kind": "generate", "provider": "qwen", "key": "<百炼 key>", "prompt": "…", "ratio": "3:4",
 "model": "qwen-image-3.0-pro", "base_url": "https://dashscope.aliyuncs.com/api/v1",
 "purpose": "training",
 "references": [{"name": "林悦.jpg", "data": "data:image/jpeg;base64,…"}]}
```

**拆层（固定 MaaS）**

```json
{"kind": "split", "provider": "maas", "key": "<MaaS key>", "prompt": "<图层规划>", "ratio": "auto",
 "image": "data:image/png;base64,…"}
```

| 字段 | 规则 |
| --- | --- |
| `kind` | `generate` 或 `split` |
| `key` | 必填，最长 512 字符，不能包含换行 |
| `prompt` | 必填，最长 16000 字 |
| `ratio` | `auto`、`1:1`、`9:16`、`16:9`、`5:2`、`4:3`、`3:4` |
| `provider` | `maas`（默认）或 `qwen`；只对生成任务有效 |
| `model` | 千问必填，只能由字母、数字、下划线、`.` 和 `-` 组成，1–100 个字符 |
| `base_url` | 千问必填，必须以 `https://` 开头，最长 500 字符 |
| `purpose` | 千问必填，取值 `cover`、`training`、`free`，用于决定 `auto` 比例对应的出图尺寸 |
| `references` | 千问可选，最多 10 张，每张必须是 PNG、JPEG 或 WebP，且不超过 20 MB；实际发送张数受模型上限限制 |
| `image` | 拆层必填，规则同上 |

响应：`202 {"id": "<任务id>"}`。已经有 2 个任务在运行时返回 `429`。

### GET /api/jobs/&lt;id&gt;

```json
{"id": "…", "kind": "generate", "status": "done", "elapsed": 38.2,
 "images": [{"url": "/output/<id>/image-01.png", "name": "image-01.png"}],
 "warnings": ["参考图超过模型上限 3 张，已舍弃 1 张讲师肖像。"],
 "zip_url": "/output/<id>/images.zip", "usage": {}}
```

- `status` 依次为 `queued`、`running`，最后是 `done` 或 `error`。
- 出错时带 `error` 字段，内容为中文说明，Key 已替换成 `[REDACTED]`。
- 前端每 1.5 秒轮询一次，最长等待 12 分钟。

### POST /api/extract

```json
{"key": "<百炼 key>", "model": "qwen-plus", "base_url": "https://dashscope.aliyuncs.com/api/v1",
 "text": "粘贴的通知原文"}
```

也可以传文件，此时不传 `text`：

```json
{"key": "…", "model": "qwen-plus", "base_url": "…",
 "file": {"name": "通知.docx", "data": "data:…;base64,…"}}
```

- 支持的文件：`.txt`、`.md`、`.markdown`、`.docx`，不超过 10 MB。`.doc` 和 PDF 会返回 400 和处理建议。
- 原文超过 20000 字时，只把前 20000 字发给模型。

响应：

```json
{"values": {
   "topic": "", "audiences": [], "date": "YYYY-MM-DD", "time": "HH:MM", "venue": "", "format": "线下",
   "headline": "", "sub": "", "cta": "", "courseList": [],
   "speakers": [{"name": "", "title": "", "bio": ""}]
 },
 "chars": 539, "truncated": false}
```

`values` 已按表单限制规整过：

| 字段 | 限制 |
| --- | --- |
| `audiences` | 只会出现 `新员工`、`管理层`、`技术人员`、`销售团队`、`全体员工`、`客户与合作方` |
| `format` | `线下`、`线上`、`混合` 之一 |
| 长度上限 | `topic`、`venue` 80 字；`headline`、`cta` 40 字；`sub` 60 字；单条课程 40 字；`name` 20 字；`title` 40 字；`bio` 80 字 |
| 数量上限 | 最多 8 条课程、6 位讲师 |

### POST /api/assets/delete 与 /api/assets/restore

请求：`{"id": "<素材id>"}`，id 只允许字母、数字、`_` 和 `-`，最长 128 个字符。成功返回 `{"ok": true}`。任务还在运行时不能删除。

### GET /api/assets

```json
{"assets": [{"id": "…", "kind": "generate", "model": "qwen-image-3.0-pro", "created_at": 1795229522.7,
   "elapsed": 38.2, "prompt": "…", "ratio": "3:4",
   "images": [{"name": "image-01.png", "url": "/output/<id>/image-01.png"}],
   "source_url": null, "zip_url": "/output/<id>/images.zip"}]}
```

列表按时间倒序，跳过没有 manifest 或图片缺失的目录。旧记录没有 `model` 字段时，按任务类型补上 MaaS 的默认模型名。

## 产物目录 output/&lt;id&gt;/

| 文件 | 说明 |
| --- | --- |
| `image-01.png` | 生成结果 |
| `layer-01.png …` | 拆层结果，顺序与模型返回的一致 |
| `source.png`（或 `.jpg`、`.webp`） | 拆层时用的原图 |
| `ref-01.jpg …` | 千问生成时用的讲师肖像，仅留档，**不进 ZIP** |
| `prompt.txt` | 实际发送的提示词 |
| `images.zip` | 结果图、`manifest.json` 和 `prompt.txt` 打包 |
| `manifest.json` | 见下 |

```json
{"kind": "generate", "provider": "qwen", "model": "qwen-image-3.0-pro", "ratio": "3:4",
 "prompt": "…", "images": [{"url": "…", "name": "image-01.png"}], "source_name": null,
 "warnings": [], "elapsed": 38.2, "usage": null, "created_at": 1795229522.7, "note": "…"}
```

**兼容性**：原 Cover Studio 生成的记录没有 `provider`、`model`、`warnings` 字段，读取时必须容忍缺失。

## 前端模块对外函数

### TrainingPoster（training-prompt.js）

```text
compile(values, {ratio, provider, maxRefImages}) → {prompt, references}
  values     = {topic, audiences[], date, time, venue, format, headline, sub, cta, courseList[],
                lecturerMode: 'feature'|'portrait'|'text', speakers[]}
  speaker    = {name, title, bio, pose, outfit, photoName}   // photoName 为空表示没有肖像
  references = 要发送肖像的讲师在 speakers 里的下标，升序排列
  主题为空时抛出 Error('请先填写培训主题。')
example() → 示例表单值
defaultSpeaker(i) → 默认讲师；姿势和着装按序号轮换
POSES, OUTFITS, AUDIENCES, FORMATS, LECTURER_MODES
```

### TrainingForm（training-form.js）

```text
mount(element)                         渲染表单；读回 localStorage，没有存档时用示例
read() → values                        当前表单值（photoName 取自已上传的肖像）
write(values)                          写入表单（会清空肖像和 AI 识别标记）
state() → {values, photos}             快照，含肖像
restore({values, photos})              恢复快照
persist()                              文字字段写入 localStorage
photo(i) → {name, dataUrl} | null
photoCount() → number                  「仅文字」模式下为 0
summary(values?) → '主题 · N 位讲师'
setRefLimit({provider, maxRefImages})  刷新弹窗里的肖像上限提示
setExtractor(async body => result)     由 app.js 注入 /api/extract 调用
mergeExtracted(state, extracted) → {values, photos}   识别结果替换整张表单，同名讲师保留肖像
```

### PunkCover（punk-cover.js）

```text
compile(style, title, context, ratio) → prompt   标题为空时抛出 Error('请先填写封面标题。')
```

### StudioConfig（config.js）

```text
ready: Promise<{source, default_key, default_qwen_key, gen_provider, qwen_image_model, qwen_text_model, qwen_base_url}>
```

## 浏览器存储

| localStorage 键 | 内容 |
