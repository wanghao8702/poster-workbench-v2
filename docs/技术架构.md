# 技术架构

## 总览

| 部分 | 技术 |
| --- | --- |
| 后端 | Python 3.10+ 标准库：`http.server` 加线程池，只监听 `127.0.0.1` |
| 前端 | 单页原生 HTML / CSS / JS，无构建、无框架 |
| 模型 | 千问（阿里云百炼）负责生图和文本识别；蚂蚁数科 MaaS 负责拆层，也可用于生图 |
| 存储 | 产物存在磁盘 `output/`；设置存在浏览器 localStorage；Key 只在页面内存里 |

```text
浏览器 (static/*)                          本机服务 (server.py)                   上游
──────────────────                        ───────────────────                    ────
弹窗表单 ──compile──▶ 完整提示词
   │                     │
   │            POST /api/jobs {kind:generate, provider, references…}
   │                     ├────────────▶ validate_job_payload ─▶ 线程池 run_job ─┬▶ 千问 qwen_client.request_image
   │                     │                                                    └▶ MaaS /images/generations
   │            GET /api/jobs/<id>（每 1.5 秒轮询）◀── JOBS 内存表
   │                     ▼
   │            画布预览 ──「继续拆解」──▶ POST /api/jobs {kind:split, image} ─▶ MaaS /images/edits
   │                                                                               │
   │            图层编辑器 ◀──────── output/<id>/layer-*.png ◀────────────────────┘
   │
   └─ AI 识别填入 ── POST /api/extract（同步）──▶ training_extract ─▶ 千问文本模型（OpenAI 兼容）
```

- 生成和拆层是**异步任务**：提交后拿到任务 id，前端轮询。最多同时跑 2 个任务，前端最长等 12 分钟。
- AI 识别是**同步请求**，一般 5–20 秒返回。

## 后端

### 服务与任务（server.py）

- `Handler`：处理所有路由，完整列表见 [接口文档](接口文档.md)。`local_request()` 校验 Host 和 Origin，挡住其他网页的跨站调用。
- `validate_job_payload()`：集中校验任务参数（比例白名单 `RATIOS`、品类白名单 `PURPOSES`、模型名、https 地址、参考图），返回 `run_job` 需要的参数。
- `run_job()`：在线程池里执行，状态写进内存字典 `JOBS`，状态依次为 `queued → running → done` 或 `error`。完成后在 `output/<id>/` 写入图片、`manifest.json`、`prompt.txt` 和 `images.zip`。服务重启后 `JOBS` 会清空，但素材库每次都从磁盘读取。
- `list_assets()` 和 `move_asset()`：素材库的列表、删除和恢复。删除只是把目录移进 `output/.trash/`。
- `http_error_message()`：把上游 HTTP 错误转成中文提示，并把 Key 脱敏。所有上游调用都走这一个函数。
- `extract_request()`：AI 识别的入口，同步执行。

### 千问生图

`qwen_client.py`，移植自 `ref培训海报生成器/ai-proxy.js`。

- `detect_protocol(model, base_url)`：
  - Base URL 含 `/api/v1` 时，走**百炼原生 DashScope 接口** `/api/v1/services/aigc/multimodal-generation/generation`。
  - 百炼官方域名的 `compatible-mode` 地址配图像模型时，**也要改走原生接口**。实测兼容模式没有 `/images/generations`，会返回 404。
  - 其他 `compatible-mode` 地址走兼容模式，请求 `/images/generations`。
- 原生接口可能 **HTTP 200 却在正文里用 `code`、`message` 表示失败**，需要检查正文。
- 原生接口返回的是 24 小时有效的临时链接，`download_image()` 拿到后立即下载（只允许 https，单张上限 20 MB）。下载失败报「结果图片下载失败」，和 Key 错误区分开。
- `max_ref_images()`：模型名含 `qwen-image-2.1` 为 10 张，其余为 3 张。超出的部分截掉，并在结果里返回 warning。
- `qwen_size()`：画面比例和出图尺寸的对应关系写在 `SIZES` 里；`auto` 按品类取默认比例（`AUTO_RATIO`）。
- 请求固定 `n: 1`、`prompt_extend: false`（不让模型改写我们拼好的提示词）；原生接口另加 `watermark: false`。

MaaS 生图和拆层沿用 Cover Studio 原有的调用方式，直接写在 `run_job` 里，调用 `https://maas-api.antdigital.com/v1` 的 `/images/generations` 和 `/images/edits`。

### AI 识别填入（training_extract.py）

1. `read_document(name, blob)` 读取上传的文件：
   - `.txt`、`.md`：先按 UTF-8（带 BOM 也可）解码，失败再按 GB18030 解码。
   - `.docx`：用 `zipfile` 加 `ElementTree` 读 `word/document.xml`，按段落提取文字，表格里的内容也会读到，不依赖 python-docx。
   - `.doc` 和 PDF 直接拒绝。
2. `server.extract_request`：原文超过 2 万字时截断，并返回 `truncated: true`。
3. `extract_training()`：
   - 请求 `chat_url(base_url)`，即与生图同一个百炼域名下的 `/compatible-mode/v1/chat/completions`。
   - 参数：`response_format: json_object`、`enable_thinking: false`、`temperature: 0.1`。
   - system 提示词（`_system_prompt`）里写明了字段说明、今天的日期，以及「不要编造、不要把主持人和联系人当讲师」等规则。
4. `normalize_training()`：把模型返回的结果规整到表单能接受的范围，包括选项白名单、日期和时间格式、长度上限 `LIMITS`、最多 6 位讲师和 8 条课程。**无论模型返回什么，都不会让表单出错。**

## 前端

### 模块分工

| 文件 | 职责 | 依赖 DOM |
| --- | --- | --- |
| `training-prompt.js` | 培训表单的值 → 提示词，并算出哪些讲师要发肖像 | 否，Node 可直接 `require` |
| `punk-cover.js` | 封面风格加标题 → 提示词 | 否 |
| `training-form.js` | 培训弹窗表单、肖像压缩（长边 1600 px 的 JPEG）、AI 识别面板 | 是 |
| `config.js` | 读取 `/api/config` | 否 |
| `app.js` | 其余全部 | 是 |

脚本有加载顺序要求：`punk-cover → training-prompt → config → training-form → app`。

### app.js 的分区

| 位置（按顺序） | 内容 |
| --- | --- |
| 顶部 | 品类配置 `PURPOSE_RATIO`、`PROMPT_IDS`、`DIALOG_IDS`；`lastCompiled`、`staleCategories` |
| `genSettings` 一带 | API 设置的读取与记忆、`resyncPrompts`、`updateGenUI`、AI 识别接线 `TrainingForm.setExtractor` |
| `compileFor` / `openSettings` / `closeSettings` | 两个设置弹窗 |
| `renderStyleGrid` | 封面风格的图片选择器（隐藏的 `#style-select` 是唯一数据来源） |
| `loadSource` / `loadExample` / `clearStage` | 画布内容的载入与清空 |
| `jobPayload` / `confirmStale` / `submit` | 提交任务与轮询 |
| `Persistent asset library` 注释之后 | 素材库 |
| `Layers` 注释之后 | 图层编辑器：绘制、选择、拖动、缩放、撤销、右键菜单、导出（基本沿用 Cover Studio） |

### 提示词一致性的状态模型

这是前端最核心、也最容易改坏的部分。要同时守住两条：

- **提示词里写的讲师肖像，必须和实际发给模型的肖像一致**；
- **用户手改过的提示词，不能被悄悄覆盖**。

```text
          弹窗「保存」 ── 手改过？──是──▶ confirm 覆盖
               │                          │
               ▼                          ▼
      applyCompiled ──▶ lastCompiled[品类] = {prompt, ratio, provider, maxRefImages}
                                   │
  生图接口 / 模型 / 比例变化 ──▶ resyncPrompts
                                   ├─ 没手改：静默重拼
                                   └─ 手改过：staleCategories.set(品类, 原因) ─▶ 显示「重新拼装」提示条
  从素材库载入历史提示词，且与表单拼出的不同 ─▶ staleCategories.set(品类, 历史原因)
  点「生成」时 staleCategories 有当前品类 ─▶ confirmStale 二次确认
  jobPayload ─▶ 用当前表单重新 compile 一次，按返回的 references 下标取肖像
```

- `isHandEdited(current, last)`：提示词框不为空，并且和上次拼出的不一样，就算手改过。
- 封面提示词与生图接口无关，只有比例变化时才需要重拼（`stampMatches`）。

### 弹窗

- 打开时保存快照（`dialogSnapshot`）。取消、✕、Esc 都恢复快照，所以 AI 识别的结果在点「取消」后也会撤回。
- 保存时调用 `compileFor(category)`。出错就在弹窗内显示，不关闭弹窗。
- 弹窗是模态的，打开期间页面其他部分不能操作。

## 数据与存储

| 数据 | 位置 | 生命周期 |
| --- | --- | --- |
| 生成结果、图层、讲师肖像留档 | `output/<任务id>/` | 一直保留，直到在素材库删除（移进 `.trash`） |
| 任务进度 | 服务内存 `JOBS` | 服务重启后清空 |
| 培训表单文字 | localStorage `poster-v2-training` | 浏览器本地，不含肖像 |
| 生图和文本模型设置 | localStorage `poster-v2-gen` | 浏览器本地，不含 Key |
| API Key | 页面内存 | 刷新即清空；本机 Key 文件会在启动时自动填入 |
| 图层编辑状态（位置、缩放、显隐） | 页面内存 | 不保存，需要导出合成 PNG |

字段细节见 [接口文档](接口文档.md)。

## 安全设计

- **只允许本机访问**：服务只监听 `127.0.0.1`，并校验 Host 和 Origin。
- **页面安全策略（CSP）**：`default-src 'self'`，禁止内联脚本和内联样式，禁止页面被嵌入其他网页。
- **Key 不落地**：不写入 manifest、`prompt.txt`、日志、localStorage；上游返回的报错里如果带了 Key，也会被替换成 `[REDACTED]`；服务不记录访问日志。
- **防路径穿越**：静态文件和产物路径都要求解析后仍在 `static/` 或 `output/` 目录里面；素材 id 只允许字母、数字、`_` 和 `-`。
- **限制上传**：请求体最大 64 MB；图片按文件头判断格式，单张最大 20 MB；识别用的文件最大 10 MB，docx 内的正文 XML 最大 20 MB。
- **外发数据**：讲师肖像和 AI 识别的原文会发送给用户自己配置的千问服务，界面和 README 里都有说明。
